# AI가 만든 티가 나는 신호

모델이 아무 지시 없이 만든 화면은 놀랄 만큼 비슷하다. 하나하나는 문제가 아니어도
여러 개가 겹치면 사람들은 바로 알아본다. 화면을 다 만든 뒤 스크린샷을 보면서 이 목록과 대조한다.
검사기가 잡는 항목은 규칙 이름을 붙였다. 나머지는 눈으로 확인해야 한다.

## 색

- **보라·남색 그라데이션**(인디고→바이올렛) 배경이나 버튼. 가장 흔한 신호다(`ai-gradient`).
- 강조색이 여러 개. 소비자 서비스는 보통 **강조색 하나 + 회색 단계**로 끝난다. 상태색(빨강=오류, 초록=완료)은 따로.
- 형광에 가까운 원색 강조, 검정 배경 + 네온.
- 회색에 파란 기가 도는 Tailwind 기본 slate 계열만으로 된 화면. 회색은 프로젝트 톤에 맞춰 고른다.

## 모양

- 모든 블록이 흰 카드 + 큰 그림자 + 큰 둥근 모서리(24px 이상). 구분선이나 배경색 차이로 나누면 훨씬 가볍다(`ai-shadow`).
- 반투명 블러(glassmorphism) 카드(`ai-glass`).
- 아이콘 + 제목 + 설명 세 줄짜리 카드가 3개 또는 4개 나란히. "특징 소개" 섹션의 전형이다.
- 동그란 배경 위에 아이콘을 올린 장식. 아이콘은 필요한 곳에만, 장식용 배경 없이.
- 모든 것을 가운데 정렬. 국내 서비스 화면은 왼쪽 정렬이 기본이다.
- 큰 숫자 통계 띠("99.9% 만족도 · 10K+ 사용자 · 24/7 지원").

## 글

- 이모지가 들어간 제목·버튼(`emoji-icon`).
- "새로운 경험", "혁신적인", "~의 모든 것", "당신만을 위한" 같은 빈 헤드라인.
- 영어 문장을 옮긴 듯한 문장: "~을 통해", "~에 있어서", "~하는 것이 가능합니다".
- 말투 섞임, 느낌표, "클릭하세요"(`copy-tone-mix`, `copy-exclaim`, `copy-click`).
- 가짜 후기, 가짜 로고 띠("Trusted by" + 회색 로고 6개).

## 내용

- 자리표시 데이터: "홍길동", "상품명", "John Doe", 모두 같은 가격, 모두 별점 5.0.
  예시라도 실제 같은 데이터를 쓴다. 상호명 길이, 가격, 평점, 후기 수가 제각각이어야 진짜처럼 보인다.
- 사진 대신 추상 일러스트나 그라데이션 블롭. 소비자 서비스는 실물 사진이 신뢰를 만든다.
- 빈 화면·오류·로딩 상태가 없음.

## 반대로 실서비스처럼 보이게 하는 것

- 정보 밀도: 가격·거리·평점·남은 수량이 목록에서 바로 보인다.
- 일관된 리듬: 간격이 4의 배수, 같은 종류의 요소는 같은 높이.
- 강조는 한 화면에 하나: 주 버튼 하나, 굵은 숫자 하나.
- 실제 데이터: 길이와 값이 들쭉날쭉한 진짜 같은 예시.
- 1px 구분선, 8px 회색 띠, 작은 모서리(8–16px).
- 상태 표시가 구체적: "오늘 23:00 마감", "남은 자리 2개".

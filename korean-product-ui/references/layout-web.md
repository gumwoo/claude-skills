# 웹 화면

소비자 서비스 웹(예약, 커머스, 콘텐츠, 서비스 소개)이 기준이다. 관리자·업무 시스템 화면은 다루지 않는다.

## 폭과 그리드

- 본문 최대 폭 1200px 안팎(콘텐츠형은 1080px). 좌우 여백은 데스크톱 40px, 태블릿 32px, 모바일 20px.
- 12열 그리드, 열 간격 24px. 목록은 데스크톱 3–4열, 태블릿 2열, 모바일 1열.
- 모바일 웹을 먼저 만든다. 국내 소비자 트래픽은 대부분 모바일이다. 데스크톱은 같은 내용을 넓게 펼친 버전이다.
- 1440 폭에서 내용이 화면 가운데 좁은 띠로만 있지 않게, 그리고 2560 폭에서 무한히 늘어나지 않게 최대 폭을 둔다.

## 헤더

- 높이 64px 안팎. 왼쪽 로고, 가운데 또는 왼쪽에 주 메뉴 3–5개, 오른쪽 검색·로그인·장바구니.
- 스크롤하면 고정, 아래 1px 구분선. 반투명 블러 헤더는 꼭 필요할 때만.
- 모바일에서는 로고 + 아이콘 2–3개 + 메뉴 버튼. 주 메뉴가 4개 이하면 헤더 아래 가로 탭으로 꺼내 둔다.

## 첫 화면

AI가 만든 웹은 거의 다 "가운데 정렬 큰 헤드라인 + 부제 + 버튼 두 개 + 그라데이션 배경"으로 시작한다.
소비자 서비스는 보통 첫 화면에서 바로 **쓸 수 있는 것**을 보여 준다.

- 예약·커머스: 첫 화면에 검색창이나 필터, 바로 아래 실제 상품·공간 목록.
- 서비스 소개: 왼쪽 정렬 헤드라인(무엇을 하는 서비스인지 한 문장) + 실제 제품 화면 캡처. 일러스트·3D 오브젝트보다 실물.
- 숫자로 신뢰를 줄 때는 구체적으로("누적 예약 38,214건"), 반올림한 과장 숫자("10만+ 사용자")는 피한다.

## 목록과 상세

- 목록 카드: 사진(4:3 또는 1:1) → 제목 → 보조 정보(위치·평점) → 가격. 가격은 굵게, 단위까지.
- 카드 테두리나 그림자 없이 사진 모서리만 둥글게(8–12px) 해도 충분하다.
- 상세: 데스크톱은 왼쪽 정보(사진, 설명, 후기) + 오른쪽 고정 결제/예약 박스(320–360px). 모바일은 박스가 하단 고정 CTA로 바뀐다.
- 필터는 상단 가로 칩 또는 왼쪽 사이드바(데스크톱). 적용된 필터는 칩으로 보여 주고 하나씩 지울 수 있게.

## 푸터

- 사업자 정보(상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 고객센터)는 국내 커머스에서 법적으로 필요하다.
  작은 회색 글씨로 두되 12px 이상, 대비 4.5:1 이상.
- 이용약관·개인정보처리방침 링크. 개인정보처리방침은 굵게 표시하는 것이 관례다.
- 푸터의 합쇼체 법적 문구는 검사기의 말투 검사에서 빠진다(`<footer>` 안에 둘 것).

## 반응형 확인

- 360, 390, 768, 1024, 1440 폭에서 본다. 검사기는 390(모바일)과 1440(데스크톱)을 기본으로 그린다.
- 가로 스크롤이 생기면 ERROR(`overflow-x`). 표·코드 블록처럼 가로 스크롤이 필요한 요소는 그 요소 안에서만 스크롤되게 한다.
